# HumaniX Fauna Portfolio

HumaniX Faunaの公式ポートフォリオWebサイトプロジェクトです。

## 技術スタック
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion

## ローカル開発手順

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

ブラウザで `http://localhost:3000` を開いて動作を確認してください。

## プロジェクト構造
- `src/app`: ページ・レイアウト・グローバルCSS
- `src/components`: ナビゲーション、ヒーロー、各種ポートフォリオセクションのUIコンポーネント

> 注: 「Fauna」は本プロジェクトのブランド名であり、Fauna DBは利用していません。
